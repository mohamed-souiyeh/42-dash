# Dash Project - 42 Málaga

This project is part of a **Dash challenge at 42 Málaga**.

The project is divided into two parts:
- Frontend
- Backend

---

## 📁 Frontend

The frontend is located inside the `frontend-part/app` directory.

Make sure you have installed:

- Node.js
- npm

Clone the repository:
```bash
git clone https://github.com/mohamed-souiyeh/42-dash.git
```
Navegate to the frontend app folder:
```bash
cd 42-dash/frontend-part/app
```
Install packages
```bash
npm i
```
Test in developer mode
```bash
npm run dev
```
Keep in mind that having the backend running is necessary in order to interact with the UI properly.
